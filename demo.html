🏢 商业地产投资分析系统

基于 Multi-Agent 架构的智能投资分析平台

📋 系统概述

本系统采用 主 Agent + 3个垂类 Agent 的架构，专为商业地产投资分析设计。支持市场分析、收益测算、风险合规三大核心功能。

技术栈：FastAPI + LangChain + Milvus Lite + Redis + 通义千问

✅ 市场分析 ✅ 收益测算 ✅ 风险合规 📊 RAG 知识增强
📈

市场分析 Agent

调取地产行情、政策解读、地块信息，预测市场趋势，提供市场分析报告。

💰

收益测算 Agent

计算租金收益、回报周期、IRR/NPV，评估投资项目可行性。

⚠️

风险合规 Agent

政策合规检查、风险识别、合规建议，生成风险评估报告。

🧠

RAG 知识增强

多路召回（向量检索+BM25+语义匹配）+ RRF 融合排序，提升回答准确率。

📊 功能演示

📈 市场分析示例

输入：分析上海陆家嘴商业地产投资价值

输出：

  • 写字楼平均租金：150元/平方米/月
  • 空置率：12%
  • 价格趋势：稳定
  • 市场总结：上海商业地产市场整体平稳，写字楼租金保持稳定

💰 收益测算示例

输入：建筑面积5000㎡，平均租金150元，总投资10000万

输出：

  • 年租金收入：810万元
  • 年净收益：510万元
  • 资本化率：5.1%
  • 投资回收期：19.6年

⚠️ 风险合规示例

输入：上海写字楼项目，用地5000㎡，建筑20000㎡

输出：

  • 容积率：4.0（符合要求）
  • 政策风险：中等
  • 市场风险：中等
  • 融资风险：低

🚀 启动方式

本项目需要启动 API 服务才能使用，有两种方式：

方式一：完整启动（推荐）

# 1. 启动 Redis
docker run -d --name redis -p 6379:6379 redis:7-alpine

# 2. 启动 API 服务
source venv/bin/activate
OPENAI_API_KEY="sk-sp-d77b35030e6e46e6bdc440b3107bd0b8" \
OPENAI_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1" \
uvicorn main:app --host 0.0.0.0 --port 8000

# 3. 访问
# API 文档: http://localhost:8000/docs
# 测试页面: 打开 test_demo.html

方式二：仅测试（无需 API Key）

# 启动 API 服务（使用模拟数据）
source venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000

# 访问测试页面
open test_demo.html
